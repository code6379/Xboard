# 免费节点插件

该插件从配置的 sing-box JSON 订阅地址读取免费节点，过滤推广节点后，使用插件内固定的 VLESS 模板转换并缓存。用户拉取订阅时只读取缓存，不再同步请求上游。

模板定义在 `Plugin.php` 的 `SERVER_TEMPLATE` 常量中。节点地址、端口、UUID、TLS 和传输配置由远程订阅填充，不依赖用户现有的节点；原节点列表为空或没有 VLESS 节点时，也可以合并 CF 免费节点。

插件使用 Laravel Scheduler 后台刷新缓存：调度器每分钟检查一次，只有缓存未预热或达到刷新间隔时才请求上游。默认每 30 分钟刷新一次。刷新成功后保存转换后的节点；上游超时、返回错误、无效 JSON 或空节点时保留最后一次成功的数据，默认最多保留 72 小时。首次启用后，调度器运行后的首个周期会预热缓存；用户请求不会触发同步刷新。

404 地址继续冷却到次日早上 8 点，并按配置顺序尝试后续地址。所有地址暂不可用时保留旧缓存，等待冷却结束后重试。多台应用服务器应使用共享缓存，并保证 Laravel Scheduler 的 `onOneServer` 锁可用。

## 配置

| 配置项                     | 说明                                                                                    |
|----------------------------|-----------------------------------------------------------------------------------------|
| `enabled`                  | 是否启用免费节点合并，默认关闭                                                          |
| `subscription_url`         | 免费节点订阅地址，每行一个或用英文逗号分隔；404 地址冷却至次日 8 点，并依次尝试后续地址 |
| `refresh_interval_minutes` | 后台缓存刷新间隔，1 至 1440 分钟，默认 30 分钟                                          |
| `stale_retention_hours`    | 刷新失败时保留最近成功节点的最长时间，24 至 168 小时，默认 72 小时                      |
| `allowed_group_ids`        | 允许返回免费节点的用户分组 ID，多个 ID 使用英文逗号分隔，例如 `1,2,5`                   |

只有用户的 `group_id` 命中 `allowed_group_ids` 时，插件才会读取并合并免费节点。未配置允许分组或用户分组未命中时，返回原订阅节点。项目 Console Kernel 已注册插件定时任务；服务器必须运行 Laravel Scheduler，缓存才会自动刷新。
插件只修改当前订阅请求中的节点数组，不会修改数据库中的真实节点。
