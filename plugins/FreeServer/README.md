# 免费节点插件

该插件从配置的 sing-box JSON 订阅地址读取免费节点，过滤推广节点后，使用现有 VLESS 节点作为模板转换并合并到用户订阅中。

## 配置

| 配置项              | 说明                                                                  |
|---------------------|-----------------------------------------------------------------------|
| `enabled`           | 是否启用免费节点合并，默认关闭                                        |
| `subscription_url`  | 免费节点订阅地址，必须由后台配置                                      |
| `allowed_group_ids` | 允许返回免费节点的用户分组 ID，多个 ID 使用英文逗号分隔，例如 `1,2,5` |

只有用户的 `group_id` 命中 `allowed_group_ids` 时，插件才会请求并合并免费节点。未配置允许分组或用户分组未命中时，返回原订阅节点。
插件只修改当前订阅请求中的节点数组，不会修改数据库中的真实节点。
